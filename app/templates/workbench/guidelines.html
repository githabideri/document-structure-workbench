{% trans "Structure Errors" %}

{% trans "These errors relate to the table's grid structure." %}

  • {% trans "Wrong row count" %} — {% trans "The table has too many or too few rows compared to the source." %}
  • {% trans "Wrong column count" %} — {% trans "The table has too many or too few columns." %}
  • {% trans "Bad rowspan" %} — {% trans "A cell that should span multiple rows does not, or spans the wrong number." %}
  • {% trans "Bad colspan" %} — {% trans "A cell that should span multiple columns does not, or spans the wrong number." %}
  • {% trans "Wrong cell assignment" %} — {% trans "Text is placed in the wrong cell (wrong row or column)." %}
  • {% trans "Missing cell" %} — {% trans "A cell that should exist is completely absent." %}
  • {% trans "Extra cell" %} — {% trans "A cell that should not exist is present." %}
  • {% trans "Header error" %} — {% trans "A header row is treated as body data, or body data is treated as a header." %}

{% trans "Text Errors" %}

{% trans "These errors relate to the text content within cells." %}

  • {% trans "Missing text" %} — {% trans "Text that should be in a cell is absent." %}
  • {% trans "Invented text" %} — {% trans "Text appears that is not in the source document." %}
  • {% trans "Numeric error" %} — {% trans "A number is wrong (wrong digit, missing minus sign, wrong decimal separator)." %}
  • {% trans "OCR/transcription error" %} — {% trans "Text is garbled or misread (e.g., \"0\" for \"O\", \"1\" for \"l\")." %}

{% trans "Detection and Crop Errors" %}

{% trans "These errors relate to how the table was detected and cropped from the page." %}

  • {% trans "Bad crop" %} — {% trans "Part of the table is cut off, or adjacent text/paragraphs are included." %}
  • {% trans "Bad detection" %} — {% trans "Two tables were merged into one, or one table was split into two." %}
