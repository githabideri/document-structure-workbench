Review Guidelines

Structure Errors

These errors relate to the table's grid structure.

  • Wrong row count — The table has too many or too few rows compared to the source.
  • Wrong column count — The table has too many or too few columns.
  • Bad rowspan — A cell that should span multiple rows does not, or spans the wrong number.
  • Bad colspan — A cell that should span multiple columns does not, or spans the wrong number.
  • Wrong cell assignment — Text is placed in the wrong cell (wrong row or column).
  • Missing cell — A cell that should exist is completely absent.
  • Extra cell — A cell that should not exist is present.
  • Header error — A header row is treated as body data, or body data is treated as a header.

Text Errors

These errors relate to the text content within cells.

  • Missing text — Text that should be in a cell is absent.
  • Invented text — Text appears that is not in the source document.
  • Numeric error — A number is wrong (wrong digit, missing minus sign, wrong decimal separator).
  • OCR/transcription error — Text is garbled or misread (e.g., "0" for "O", "1" for "l").

Detection and Crop Errors

These errors relate to how the table was detected and cropped from the page.

  • Bad crop — Part of the table is cut off, or adjacent text/paragraphs are included.
  • Bad detection — Two tables were merged into one, or one table was split into two.

Scoring Guide

Score Meaning
3 Correct — no errors or only trivial formatting differences.
2 Minor correction — small errors that don't affect understanding.
1 Major correction — significant errors that require manual fixing.
0 Unusable — the output cannot be used without complete re-entry.
