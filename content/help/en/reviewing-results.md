# Reviewing Results

## How to review a table extraction

1. **Compare visually**: Look at both Candidate X and Candidate Y side by side
2. **Check structure**: Do rows and columns match the original table?
3. **Check content**: Is the text in each cell correct?
4. **Score quality**: Rate each extraction from 0 (Unusable) to 3 (Excellent)
5. **Choose preference**: Which result is better, or is it a tie?
6. **Note errors**: Select any error categories that apply
7. **Submit**: Your review is saved and the model identities are revealed

## Error categories

### Structure errors
- Wrong row count
- Wrong column count
- Bad rowspan/colspan
- Missing cell
- Extra cell
- Header error

### Text errors
- Missing text
- Incorrect text
- Extra text
- Wrong formatting

### Detection errors
- Table not detected
- Wrong table detected
- Bad crop (too much/too little context)
