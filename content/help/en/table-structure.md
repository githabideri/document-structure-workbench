# Table Structure

## What is table structure?

Table structure refers to the arrangement of rows, columns, headers, and merged cells within a table. A table is not just a grid of text — it has a logical structure that defines how data is organized.

## Why does structure matter?

Correct structure is essential for:
- Understanding which cells are headers vs. data
- Identifying row and column relationships
- Handling merged cells (rowspans/colspans)
- Enabling downstream data processing and analysis

## Common structure errors

- **Wrong row count**: Too many or too few rows detected
- **Wrong column count**: Columns merged or split incorrectly
- **Header errors**: Header row treated as data, or vice versa
- **Merged cell errors**: Rowspans or colspans not represented correctly
